# Security

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's private vulnerability
reporting: **Report a vulnerability** under the repository's **Security** tab.
Do not open a public issue for one.

srcblocks is a local tool: it serves one repository on disk to a browser on the
same machine. The reports that matter most are anything that lets a web page,
or another user on that machine, read files or run commands through it.

## Supported versions

Only the latest release is supported - currently 0.1.0.
